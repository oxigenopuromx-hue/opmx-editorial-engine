## Avance de eventos multiusuario

Se preparó el guard para que, sólo si se configura explícitamente un suscriptor central y operadores autorizados, sus eventos se entreguen también a esa suscripción sin cambiar el propietario del paquete. El worker vuelve a validar relación de operadores, estado READY y revisión; el payload permanece sin contenido privado. Sin configuración, conserva el aislamiento original. La variable de entorno privada `OPMX_TELEGRAM_SHARED_OPERATORS` acepta JSON con `subscriber` y `operators` (arreglo de IDs numéricos como cadenas); nunca guardar valores privados ni secretos en Git. Una vez integrada la resolución de destinatarios y confirmado el estado, la acción autenticada emit puede generar la entrega pendiente sin volver a cerrar el paquete. No ejecutar mientras el sistema no esté integrado ni reconciliado.
